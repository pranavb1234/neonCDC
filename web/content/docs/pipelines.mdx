## Create the pipeline

1. Browse a saved database.
2. Select eligible tables.
3. Select **Create Pipeline** and provide a name.
4. Review the selection and create it.

CDC Lite validates the selected tables and logical-replication prerequisites before creating a deterministic publication and replication slot. It does not silently change replica identity or other source-table configuration.

## First-release limit

One CDC Lite installation supports one running pipeline. You can save additional pipelines, but must stop the active pipeline before starting another.

Stopping a pipeline preserves its slot and publication so it can start again. Delete becomes available after it is stopped and removes the slot and publication created for that pipeline.

## Observe changes

Make a committed `INSERT`, `UPDATE`, or `DELETE` to a table selected by the running pipeline. The event appears on **Live Events**, then is eligible for delivery to sinks linked to that same pipeline.

Only committed changes are captured. Initial table snapshots and schema evolution are outside this release's scope.
