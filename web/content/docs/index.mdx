CDC Lite watches selected PostgreSQL tables for committed `INSERT`, `UPDATE`, and `DELETE` changes. It buffers each committed event in Redis and delivers it to a configured webhook.

This documentation is the web version of the customer quick-start guide included in the Docker Compose ZIP. It covers a small, self-hosted installation: one CDC Lite server, one Redis instance, and one active pipeline at a time.

## Start here

- [Quick start](/docs/quick-start) — install the Compose package and open the console.
- [Connect PostgreSQL](/docs/postgresql) — add a database and verify logical replication.
- [Create a pipeline](/docs/pipelines) — select tables and start capture.
- [Webhooks](/docs/webhooks) — add a sink and verify signed deliveries.
- [Operations](/docs/operations) — inspect health, logs, backups, updates, and uninstall.

## Delivery guarantee

CDC Lite writes a committed transaction to Redis before it acknowledges its PostgreSQL LSN. This protects against acknowledging an event that was not buffered. It does not provide exactly-once delivery: recovery and retry can produce duplicate deliveries. Receivers must deduplicate with `X-CDC-Event-Id`.
