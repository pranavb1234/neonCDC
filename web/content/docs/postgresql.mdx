description: Save, test, and safely browse a source database.

## Add a database

1. Open **Databases** in the CDC Lite console.
2. Select **Add Database**.
3. Enter a display name and PostgreSQL connection string.
4. Select **Test Connection**.
5. Save only after both the SQL connection and logical-replication checks pass.

Saved connection strings are encrypted in the `cdc-lite-data` volume and are never returned by the API or written to logs.

## Logical replication requirements

- PostgreSQL needs `wal_level=logical`.
- The connection role needs `REPLICATION` and access to selected tables.
- The provider must allow logical replication slots and publications.
- Use TLS for remote sources: `sslmode=require`, `sslmode=verify-ca`, or `sslmode=verify-full`.
- Use a direct database endpoint. Do not use transaction pooling or a PostgreSQL `-pooler` endpoint.

For Neon, enable Logical Replication in the Neon project settings and use the direct, unpooled endpoint. Some managed PostgreSQL plans do not permit logical slots or replication roles. CDC Lite does not fall back to polling if these checks fail.

## Browse safely

Choose **Browse** on a saved database. CDC Lite lists non-system schemas and tables, then shows columns, primary keys, replica identity, and a small read-only row preview.

The browser never accepts arbitrary SQL and does not change source schema or row data. Tables without a primary key or `REPLICA IDENTITY FULL` are flagged because complete `UPDATE` and `DELETE` capture may not be available.
