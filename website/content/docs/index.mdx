CDC Lite watches selected PostgreSQL tables for committed `INSERT`, `UPDATE`, and `DELETE` changes. It buffers each committed event in Redis and delivers it to configured webhook sinks.

- [Operations](/docs/operations)

## Delivery guarantee

CDC Lite writes a committed transaction to Redis before acknowledging its PostgreSQL LSN. Recovery and retry can still cause duplicates, so receivers must deduplicate with `X-CDC-Event-Id`.
