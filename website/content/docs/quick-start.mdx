title: Quick start
description: Download the Docker Compose package, configure, and start Walflow.
---

## Prerequisites

- Docker Desktop (Windows / macOS) or Docker Engine + Compose (Linux).
- A published Walflow image — `ghcr.io/pranavb1234/walflow:latest`.
- Go, Node.js, Redis, and PostgreSQL are **not** required locally.

## 1. Download

```bash
curl -LO https://github.com/pranavb1234/walflow/releases/latest/download/Walflow-Docker-Compose.zip
```

Or download the ZIP manually from the [GitHub Releases](https://github.com/pranavb1234/walflow/releases) page.

## 2. Extract

**Windows (PowerShell):**

```powershell
Expand-Archive Walflow-Docker-Compose.zip -DestinationPath Walflow-Docker-Compose
cd Walflow-Docker-Compose
```

**macOS / Linux:**

```bash
unzip Walflow-Docker-Compose.zip -d Walflow-Docker-Compose
cd Walflow-Docker-Compose
```

## 3. Configure

Copy the example environment file:

```powershell
Copy-Item .env.example .env
```

Open `.env` in a text editor and fill in the values:

### `WALFLOW_IMAGE`

Set this to the Walflow Docker image:

```ini
WALFLOW_IMAGE=ghcr.io/pranavb1234/walflow:latest
```

To pin a specific version, replace `latest` with a version tag (e.g. `ghcr.io/pranavb1234/walflow:0.1.0`).

### `APP_ENCRYPTION_KEY`

Generate a 32-byte Base64 key (run once, save forever):

```powershell
$bytes = New-Object byte[] 32
[System.Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($bytes)
[Convert]::ToBase64String($bytes)
```

Paste the output into `.env`. This key encrypts saved connection strings and webhook secrets — do not lose it.

### Admin credentials

Set `ADMIN_EMAIL` and `ADMIN_PASSWORD` (minimum 12 characters).

### Complete `.env` example

```ini
WALFLOW_IMAGE=ghcr.io/pranavb1234/walflow:latest
WALFLOW_PORT=3000
APP_ENCRYPTION_KEY=<your-generated-key>
ADMIN_EMAIL=you@example.com
ADMIN_PASSWORD=your-secure-password
```

## 4. Start

```powershell
docker compose up -d
docker compose ps
```

When `walflow-server` shows as **healthy**, open [http://localhost:3000](http://localhost:3000).

## What Compose starts

`docker compose up -d` starts two services:

| Service | Description |
|---|---|
| `walflow-server` | The console, connector, and delivery worker |
| `redis` | Internal event buffer |

PostgreSQL is **not** started — connect your existing source database through the console. Configuration is stored in the `walflow-data` volume and Redis data in `walflow-redis-data`.

## Security note

The first startup saves the administrator email and password hash. The current release does not yet enforce a login screen, so run it only on a trusted local machine or protected private network.
